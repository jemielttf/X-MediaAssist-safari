X Media Assist

Xに投稿された動画とGIFアニメを保存します。

Safariの設定で拡張機能を有効にしてください。

Safari拡張機能は有効です。

Safari拡張機能は無効です。

  1. Safariの「設定 → 拡張機能」で有効にします。
  2. Xの投稿を開き、サイトへのアクセスを許可します。
  3. 「動画を保存」でダウンロードフォルダに保存します。

動画はMP4、GIFアニメはGIFで保存します。GIFに変換できなかった場合は、MP4で保存します。
投稿内にボタンがない場合は、Safariの拡張ボタンからURLを入力できます。
