X Media Assist

Save videos and animated GIFs from X.

Enable the extension in Safari Settings.

How to Use

  1. 1Enable X Media Assist in Safari → Settings → Extensions.
  2. 2Open a post on X and allow access to the website.
  3. 3Click “Save Video” to save to Downloads.

Notes

  • Videos are saved as MP4 and animated GIFs as GIF. If GIF conversion fails, the MP4 is saved instead.
  • If a post has no save button, enter its URL using the extension button in Safari.
  • Use the menu bar icon to manage Dock visibility and launching at login. The app keeps running when you close this window.
