# X Media Assist for Safari

Xに投稿された動画とGIFアニメを、Macのダウンロードフォルダへ保存するSafari拡張機能です。動画はMP4、GIFアニメはGIFで保存します。

## はじめに

macOS 14以降が対象です。通常は配布ページからビルド済みのアプリを入手してください。

1. 入手した **X Media Assist.app** を「アプリケーション」フォルダに移し、起動します。
2. アプリの「Safariの拡張機能設定を開く」から、Safariの拡張機能 **X Media Assist** を有効にします。
3. 利用するSafariプロファイルで、Xと `cdn.syndication.twimg.com` へのアクセスを許可します。
4. Xの投稿を開き、「動画を保存」を押します。保存が完了するまでタブを開いておいてください。

投稿内にボタンがない場合は、Safariのツールバーにある拡張ボタンから投稿URLを入力して保存できます。ここでは「Auto」（動画はMP4、GIFアニメはGIF）と「MP4」を選べます。

## 保存について

- 保存先はMacのダウンロードフォルダです。同じ名前のファイルがあっても上書きしません。
- GIFアニメは、Xから取得した動画をGIFへ変換します。元のGIFファイルを復元する機能ではありません。変換できない場合はMP4で保存します。
- 公開されている投稿の動画とGIFアニメが対象です。非公開・削除済み・閲覧制限のある投稿、静止画、ライブ配信には対応していません。引用された動画は、引用元の投稿を開いて保存してください。
- 保存結果を確認できない表示が出た場合は、再試行する前にダウンロードフォルダを確認してください。

## アプリの設定

起動中はメニューバーにアイコンが表示されます。ウインドウを閉じてもアプリは動作し、メニューから再表示・終了できます。「Dockに表示しない」と「ログイン時に起動する」もここで設定できます。ログイン時起動を使う場合は、アプリを「アプリケーション」フォルダなど継続して利用する場所に置いてください。

## 自分でビルドする場合

ソースコードは[GitHubのリポジトリ](https://github.com/jemielttf/X-MediaAssist-safari)で公開しています。配布版と同じソースからビルドする場合は、配布ページに記載されたリリースタグを確認してください。XcodeとRustが必要です。取得方法、署名設定、ビルド手順は[開発用README](README_DEV.md#起動)を参照してください。
