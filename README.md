# X Media Assist for Safari

Xに投稿された動画とGIFアニメを、Macのダウンロードフォルダへ保存するSafari拡張機能です。動画はMP4、GIFアニメはGIFで保存します。

## はじめに

macOS 14以降のApple Silicon搭載Macのみ対応しています。Intel搭載Macには対応していません。通常は[配布ページ（GitHub Releases）](https://github.com/jemielttf/X-MediaAssist-safari/releases)からビルド済みのアプリを入手してください。

1. 入手した **X Media Assist.app** を「アプリケーション」フォルダに移し、起動します。
2. アプリの「Safariの拡張機能設定を開く」から、Safariの拡張機能 **X Media Assist** を有効にします。
3. 利用するSafariプロファイルで、Xと `cdn.syndication.twimg.com` へのアクセスを許可します。
4. Xの投稿を開き、「動画を保存」を押します。保存結果が表示されるまでタブを開いておいてください。

投稿内にボタンがない場合は、Safariのツールバーにある拡張ボタンから投稿URLを入力して保存できます。ここでは「Auto」（動画はMP4、GIFアニメはGIF）と「MP4」（GIFアニメもMP4で保存）を選べます。保存結果が表示されるまでポップアップを開いておいてください。

## 保存について

- 保存先はMacのダウンロードフォルダです。同じ名前のファイルがあっても上書きしません。
- GIFアニメは、Xから取得した動画をGIFへ変換します。元のGIFファイルを復元する機能ではありません。変換できない場合はMP4で保存します。
- GIF変換には長さ30秒、入力・出力各100 MiBなどの上限があります。上限を超えた場合や、別のGIFを変換中の場合も、MP4で保存して理由を表示します。
- 公開されている投稿の動画とGIFアニメが対象です。非公開・削除済み・閲覧制限のある投稿、静止画、ライブ配信には対応していません。引用された動画は、引用元の投稿を開いて保存してください。
- 保存結果を確認できない表示が出た場合は、再試行する前にダウンロードフォルダを確認してください。

## アプリの設定

起動中はメニューバーにアイコンが表示されます。ウインドウを閉じてもアプリは動作し、メニューから再表示・終了できます。「Dockに表示しない」と「ログイン時に起動する」もここで設定できます。ログイン時起動を使う場合は、アプリを「アプリケーション」フォルダなど継続して利用する場所に置いてください。

アプリの管理画面でGIFの基本設定を変更できます。変更は自動保存されます。

| 項目 | 選択肢 | 初期値 |
| --- | --- | --- |
| 画質 | 高 / 中 / 低 | 高 |
| 最大フレームレート | 30 / 25 / 20 / 15 fps | 20 fps |
| 出力サイズ | 100% / 75% / 50% | 100% |

最大フレームレートは、元のタイミングを保ちながらフレーム数を抑える目安です。固定のfpsに変換する設定ではありません。30fpsを上限20fpsにすると約20fpsに間引き、15fpsを上限20fpsにしてもフレームを増やしません。フレーム間隔は一定ではなく、短い表示時間の調整などにより実際の枚数が設定値より少なくなる場合があります。

出力サイズは縦・横それぞれの倍率です。例えば1280 × 720の映像を75%にすると960 × 540、50%にすると640 × 360になります。映像の向きを反映した後、縦横の比率を保って縮小します。ファイル容量を抑えたい場合は、画質・最大フレームレート・出力サイズを下げてください。

Safariのツールバーポップアップでは、同じ3項目を今回の保存用に変更できます。基本設定には保存されず、開き直すと基本設定に戻ります。MP4選択時はGIF設定を使用しません。

## 自分でビルドする場合

ソースコードは[GitHubのリポジトリ](https://github.com/jemielttf/X-MediaAssist-safari)で公開しています。配布版と同じソースからビルドする場合は、配布ページに記載されたリリースタグを確認してください。XcodeとRustが必要です。取得方法、署名設定、ビルド手順は[開発用README](README_DEV.md#起動)を参照してください。
