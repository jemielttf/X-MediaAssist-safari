# X Media Assist for Safari

Xに投稿された動画やGIFアニメを、Macのダウンロードフォルダへ保存するSafari拡張機能です。
動画はMP4、GIFアニメはGIFで保存します。

## 動作環境

- macOS 14以降
- Apple Silicon搭載Mac（Intel搭載Macには対応していません）

## インストール

以下の２種類のインストール方法があります。

### 方法1: Homebrewでインストールする

[Homebrew](https://brew.sh/ja/) を導入済みの場合は、ターミナルで次のコマンドを実行するだけです。

```bash
brew install --cask jemielttf/tap/x-media-assist
```

更新するときは、こちらを実行してください。

```bash
brew update
brew upgrade --cask jemielttf/tap/x-media-assist
```

### 方法2: GitHub Releasesからダウンロードする

1. [配布ページ](https://github.com/jemielttf/X-MediaAssist-safari/releases) から `X-Media-Assist-<バージョン>.zip` をダウンロードします。
2. ダウンロードしたファイルを展開します。
3. 中の **X Media Assist.app** を「アプリケーション」フォルダへ移動します。

## はじめかた

どちらの方法でインストールした場合も、最初に一度だけ次の設定をします。

1. **X Media Assist.app** を起動します。
2. 「Safariの拡張機能設定を開く」を押し、Safariの拡張機能 **X Media Assist** をオンにします。
3. 利用するSafariプロファイルで、`x.com` と `cdn.syndication.twimg.com` へのアクセスを許可します。

これで準備は完了です。

## 動画を保存する

### 投稿から保存する

1. Safariで、保存したい動画やGIFアニメがあるXの投稿を開きます。
2. 投稿内の **「↓ 動画を保存」** を押します。
3. 保存結果が表示されるまで、そのままタブを開いておきます。

### 投稿URLから保存する

投稿内にボタンが見つからないときは、URLを入力して保存できます。

1. Safariのツールバーにある **X Media Assist** のボタンを押します。
2. 投稿のURL（`https://x.com/ユーザー名/status/投稿ID` の形式）を入力します。Xの投稿を開いた状態でボタンを押すと、そのURLが自動で入ります。
3. 保存形式を選んで、**「動画を保存」** を押します。
4. 保存結果が表示されるまで、ポップアップを開いておきます。

| 保存形式 | 保存されるファイル |
| --- | --- |
| Auto（初期値） | 動画はMP4、GIFアニメはGIF |
| MP4 | 動画・GIFアニメともにMP4 |

投稿内の保存ボタンは常にAutoで保存します。

## 保存について

保存先はMacのダウンロードフォルダです。同じ名前のファイルがある場合は、別名で保存し、上書きしません。

| 対象 | 対応状況 |
| --- | --- |
| 公開されている投稿の動画・GIFアニメ | 保存できます |
| 非公開・削除済み・閲覧制限のある投稿 | 保存できません |
| 静止画・ライブ配信 | 保存できません |

## GIFアニメについて

- Xでは、GIFアニメは動画として配信されています。このアプリは、取得した動画をGIFに**変換**して保存します。元のGIFファイルをそのまま取り出す機能ではありません。
- GIFに変換できなかった場合は、代わりに**MP4で保存**し、その理由を表示します。たとえば次のようなときです。
  - 長さが30秒を超えている
  - 入力・出力のファイルサイズが、それぞれ100 MiBを超える
  - 解像度やフレーム数が上限を超えている、または変換に時間がかかりすぎた
  - 別のGIFを変換中である

## GIFの画質を設定する

画質やファイルサイズは、次の3項目で調整できます。

| 項目 | 選択肢 | 初期値 |
| --- | --- | --- |
| 画質 | 高 / 中 / 低 | 高 |
| 最大フレームレート | 30 / 25 / 20 / 15 fps | 20 fps |
| 出力サイズ | 100% / 75% / 50% | 100% |

**ファイルを小さくしたいときは、画質・最大フレームレート・出力サイズのいずれか（または複数）を下げてください。**

### 設定できる場所

- **アプリの管理画面**: ふだん使う設定です。変更は自動で保存されます。
- **Safariのツールバーのポップアップ**: ポップアップからの動画保存時に一時的に使用される設定です。基本設定は書き換わらず、開き直すと基本設定に戻ります。

MP4を選んだ場合、GIFの設定は使われません。

### 設定の目安

**最大フレームレート**は、元の動きのタイミングを保ったまま、フレーム数を減らすための上限です。「固定のfpsに変換する」設定ではありません。

- 30fpsの映像を上限20fpsにすると、約20fpsに間引きます。
- 15fpsの映像を上限20fpsにしても、フレームは増えません。
- フレーム間隔は一定ではありません。また、表示時間がごく短いフレームの調整などにより、実際の枚数が設定値より少なくなることがあります。

**出力サイズ**は、縦・横それぞれの倍率です。映像の向きを反映したあと、縦横比を保ったまま縮小します。

| 元の映像 | 75% | 50% |
| --- | --- | --- |
| 1280 × 720 | 960 × 540 | 640 × 360 |

## アプリの使いかた

起動中は、メニューバーにアイコンが表示されます。ウインドウを閉じてもアプリは動き続けるので、気軽に閉じて大丈夫です。メニューから、ウインドウの再表示や終了ができます。

メニューからは、次の設定もできます。

- **Dockに表示しない**
- **ログイン時に起動する**: 使う場合は、アプリを「アプリケーション」フォルダなど、ずっと置いておく場所に入れてください。

## うまくいかないときは

**「保存結果を確認できません」と表示された**
再試行する前に、ダウンロードフォルダを確認してください。すでに保存されている場合があります。

**「拡張機能との接続が切れました」などと表示された**
まずダウンロードフォルダを確認してください。保存されていなければ、ページを再読み込みしてから再試行します。それでも改善しない場合は、Safariを終了して起動し直し、拡張機能が有効になっているか確認してください。

**投稿にボタンが出ない**
Safariのツールバーにある拡張ボタンから、投稿URLを入力して保存できます。

**保存中に気をつけること**
保存結果が表示されるまで、タブ（またはポップアップ）を開いたままにしてください。途中で閉じると、保存結果を確認できなくなります。

**GIFではなくMP4で保存された**
上の「GIFアニメについて知っておきたいこと」の条件に当てはまっていないか確認してください。理由は保存時に表示されます。
