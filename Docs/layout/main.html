X Media Assist

Xの動画とGIFアニメを保存します。

Safari拡張機能は有効です

使い方

  1. 1Safariの「設定 → 拡張機能」で有効にします。
  2. 2Xの投稿を開き、サイトへのアクセスを許可します。
  3. 3「動画を保存」でダウンロードフォルダに保存します。

GIF設定

基本設定

通常のGIF保存に使います。変更は自動保存されます。

画質
最大フレームレート
出力サイズ

メモ

  • 動画はMP4、GIFアニメはGIFで保存します。GIFに変換できなかった場合は、MP4で保存します。
  • 投稿内にボタンがない場合は、Safariの拡張ボタンからURLを入力できます。
  • メニューバーのアイコンから、Dock表示とログイン時起動を設定できます。ウインドウを閉じても常駐を続けます。
